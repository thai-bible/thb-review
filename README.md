# THB Review — ตรวจทานคำแปลพระคัมภีร์ภาษาไทย THB

เว็บไซต์: **https://thai-bible.github.io/thb-review/**

THB คือพระคัมภีร์ภาษาไทยที่แปลจาก World English Bible (WEB) และเผยแพร่เป็น public domain (CC0) repo นี้เก็บหน้าตรวจทานที่แสดงต้นฉบับ WEB คู่กับร่างคำแปลไทยทีละข้อ พร้อมเชิงอรรถและสถานะ

## วิธีช่วยตรวจทาน

1. เปิดหน้าเว็บด้านบน แล้วเลือกเล่ม
2. อ่านต้นฉบับ WEB เทียบกับคำแปล THB
3. ถ้าพบจุดที่ควรแก้ กด **“เสนอแก้”** ที่ข้อนั้น ระบบจะเปิด GitHub Issue ที่กรอกรหัสข้อ ต้นฉบับ และคำแปลปัจจุบันไว้ให้ พิมพ์ข้อเสนอและเหตุผลแล้วกด Submit (ต้องมีบัญชี GitHub ซึ่งสมัครฟรี)

แนวทางที่ใช้ตรวจ:

- คำแปลต้องตรงกับความหมายของ WEB ไม่ตกหล่นและไม่เพิ่มเติม
- ใช้ราชาศัพท์กับพระเจ้าและพระเยซู แปลพระนาม Yahweh ว่า "พระยาห์เวห์"
- ชื่อเฉพาะใช้รูปที่คนไทยใช้กันทั่วไป
- ภาษาไทยอ่านลื่นและเป็นธรรมชาติ

## ข้อตกลง

- ข้อเสนอที่ส่งมาถือว่ายกให้เป็น public domain ภายใต้ [CC0 1.0](LICENSE) เช่นเดียวกับคำแปล
- **ห้ามคัดลอกถ้อยคำจากพระคัมภีร์ฉบับแปลอื่นที่มีลิขสิทธิ์** (เช่น ฉบับภาษาไทยที่ยังมีลิขสิทธิ์) มาเสนอเป็นคำแปล ให้เขียนข้อเสนอเองจากความหมายของ WEB
- "World English Bible" เป็นเครื่องหมายการค้าของ eBible.org ฉบับนี้แปล *จาก* WEB ไม่ได้ใช้ชื่อ WEB
